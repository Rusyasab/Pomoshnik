# Pomoshnik

Интерактивный промо-блок «Какие задачи умеет решать Про».

## Возможности

- аккордеон из четырёх пунктов;
- первый пункт открыт по умолчанию;
- каждому пункту соответствует отдельное видео;
- crossfade между роликами — 200 мс, ease-in-out;
- фиксированная десктопная вёрстка по макету Figma.

## Запуск

Откройте `index.html` в браузере. Для загрузки видео и графических ассетов требуется интернет.

Опубликованная версия: https://neuropro-promo-ruslan.sabzrus.chatgpt.site/
